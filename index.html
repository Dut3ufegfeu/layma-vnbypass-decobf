2Logic hoạt động — bypass nhiệm vụ lấy mã layma.net

  1. Đồng bộ định danh — gọi API nội bộ của chính trang: getVisitorInfo, getVisitorUUID, trafficSessionToken để có phiên làm việc hợp lệ.
  2. Inject giao diện — chèn khung điều khiển #vnbypass-wrapper + làm sạch style bằng #vnbypass-clean-style.
  3. Nhận nhiệm vụ — tải cấu hình nhiệm vụ (ảnh/keyword cần tìm) từ paste của tác giả.
  4. Qua captcha tự động — gọi thẳng getQCaptchaToken, getTokenId, getCampainId — chính là API captcha (qcaptcha) của trang — để tự có token mà không cần giải captcha.
  5. Tự điền & nộp mã — điền #qcaptcha-checkcode, bấm qua #native-override-captcha-box / #native-override-button-box.
  6. Tự xử lý lỗi — nhiệm vụ hỏng thì AUTO_CHANGE_MISSION_ON_ERROR tự đổi nhiệm vụ khác.
  7. Kết quả — nhận mã mở khóa chương mà không phải làm thủ công.
🔧 Kỹ thuật mã hóa & cách decobf (chi tiết kỹ thuật)

Tầng 1 dùng javascript-obfuscator: string-array Base64+RC4, 125 wrapper offset, xoay mảng checksum 308604, self-defending + debug-protection. Tầng 2–4 dùng VM-lite kiểu Jscrambler (chuỗi XOR tách mảnh, TEA-16bit decrypt runtime, control-flow flatten) và tầng cuối là JSVMP thật — logic biên dịch thành bytecode, không còn chuỗi plain-text.

2Logic hoạt động — bypass nhiệm vụ traffic

  1. Inject nút nổi — nút "Delta — Mở Vnbypass CUTTAY PROMAX" (icon cdn.upanhlaylink.com/i/7LN0E0hl.ico) hiện trên mọi trang nhiệm vụ, kèm link quảng chéo layma.net (cùng tác giả).
  2. Dán link nhiệm vụ — người dùng dán link nhiệm vụ rút gọn vào panel.
  3. Resolve link — script gọi API của trang (kèm session/cookie qua GM_cookie) để tách link đích thật.
  4. Copy link đích — toast "Đã sao chép link đích vào clipboard!" qua navigator.clipboard.writeText — bỏ qua bước đợi xem quảng cáo.
  5. Nộp mã — mở link đích, lấy "mã tìm được" rồi dán vào ô của script → tự điền/nộp trên trang nhiệm vụ.
  6. Tự động hóa — lắng nghe keydown/mousemove/mouseup, chuỗi bước tự động chạy bằng setTimeout 200 ms.
