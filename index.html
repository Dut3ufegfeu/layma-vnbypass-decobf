5Logic mã hóa của từng tầng

Tầng 1 — funcion.js: javascript-obfuscator (obfuscator.io)

  1. String array — _0x55cc() trả mảng ~350 chuỗi Base64+RC4. Mọi chuỗi trong code đều thay bằng lời gọi hàm.
  2. Decoder lõi — _0x3d1b(index, key): lấy phần tử → atob → RC4(key 4 ký tự). Có memoization.
  3. 125 wrapper offset — _0x25d53f(a,b,c,d,e){return _0x3d1b(c-0x2e1, b)} — mỗi call site một bộ hex khác nhau.
  4. IIFE xoay mảng — xoay push/shift đến khi tổng parseInt khớp checksum 308604.
  5. Anti-tamper — selfDefending (indexOf('\n') + regex thảm họa (((.+)+)+)+$), debugProtection (setInterval 4s + while(true){} + debugger), tắt console.

Tầng 2–4 — x10.mx + pastefy: VM-lite kiểu Jscrambler & JSVMP

  1. Tên biến 2 ký tự (uy, AI, wa…) phá khả năng grep.
  2. Chuỗi XOR "miếng" — uy(arr, 11) dùng fromCharCode — nhưng chính chữ đó bị tách "\x66rom"+"\x43\x68ar"+"C\x6f\x64\x65".
  3. Chuỗi chính trong mảng Uint16 mã TEA-16bit: bG[Ex] ^= ((up^Ez)+qK) & 65535 — decrypt lazy runtime → URL tĩnh không thấy.
  4. Control-flow flatten — while (Mi !== 185297400) { if (Mi === 184570624) {…} }, hằng số state là phép XOR.
  5. JSVMP thật (tầng 4) — logic biên dịch thành bytecode, interpreter DataView/getInt8; 0 chuỗi plain-text trong 211 KB; opcode CALL ném TypeError(Nx+' is not a function') là "cửa" patch & trace.

6Cách decobf từng tầng

  1. Tách máy giải mã khỏi logic: Babel AST → tìm string-array → closure ngược qua các wrapper (125 hàm).
  2. Sandbox: ném function declarations (trơ) + đúng 1 IIFE xoay mảng vào Node vm — logic chính không bao giờ chạy.
  3. Evaluate từng call site: _0x…(0x…,'key',…) thuần hằng → cắt chuỗi nguồn → chạy trong sandbox → thay StringLiteral. 505/505 lời gọi được giải.
  4. Fold hằng số đến hội tụ: gộp nối chuỗi, tính -0xff3+0x1396+0xbfd, obj['push']→obj.push, !![]→true.
  5. Beautify + tái tạo src gốc bằng tay → ~15 dòng thật.
  6. Tầng VM/JSVMP: decode XOR (unescape \xNN + xóa nháy/+ trước khi tìm fromCharCode), fold bit-hằng, normalize escape; URL thật chỉ lộ khi chạy sandbox stub DOM/fetch; stage 4 — patch throw new TypeError(Nx+…) thành heal để trace toàn bộ hành vi.
